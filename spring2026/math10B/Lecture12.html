Lecture 12: Parametrization of Surfaces

Recall: Fundamental Theorem of Line Integrals

Theorem: Suppose \(\vec{F} = \text{grad } F = \nabla F\). Then, along any path \(\vec{c}(t)\), \(a \le t \le b\),

\[\int_c \vec{F} \cdot d\vec{c} = F(\vec{c}(b)) - F(\vec{c}(a))\]

This theorem essentially states that the line integral of a gradient field depends only on the endpoints \(\vec{c}(b)\) and \(\vec{c}(a)\), and not on the path itself.

Example 1: Evaluation of a Line Integral

Suppose \(F(x, y, z) = x^2 - y^2 - \sin z\). Integrate \(\nabla F\) along the semicircular curve joining \((2, 0, 0)\) and \((-1, 1, 0)\) in the \(xy\)-plane.

Visual Description: A 3D coordinate system. A path is drawn as a semi-circle in the \(xy\)-plane (where \(z=0\)). It starts at \(x=2\) on the positive \(x\)-axis and curves through the first and second quadrants to end at the point \((-1, 1)\).

Solution:

By the Fundamental Theorem of Line Integrals:

\[\int_c \nabla F \cdot d\vec{c} = F(-1, 1, 0) - F(2, 0, 0)\]

Step-by-step evaluation:

  • \(F(-1, 1, 0) = (-1)^2 - (1)^2 - \sin(0) = 1 - 1 - 0 = 0\)
  • \(F(2, 0, 0) = (2)^2 - (0)^2 - \sin(0) = 4 - 0 - 0 = 4\)

Therefore, the integral result is \(0 - 4 = -4\).

Corollary: The integral of \(\nabla F\) along any closed loop is zero. For example, the integral along the unit circle in the \(xy\)-plane is zero because the starting and ending points are identical.

Parametrization of Surfaces

Visual Description: A curved surface \(S\) is shown in 3D space. At various points on the surface, vectors labeled \(\vec{n}\) (the normal vector) point outward, perpendicular to the surface. This represents the orientation needed for flux calculations.

Our goal is to integrate scalar or vector-valued functions over 2D surfaces. For vector-valued functions, this allows us to compute the flux through a surface. The first step is defining the surface using parameters.

Transition from Curves to Surfaces

Recall that a curve is parametrized by a single variable: \(\vec{c}(t) = (x(t), y(t), z(t))\). For a 2D surface, we require two parameters, typically \(u\) and \(v\):

\[\vec{r}(u, v) = (x(u, v), y(u, v), z(u, v))\]
Example 2: Parametrizing the Unit Sphere

Consider the sphere \(x^2 + y^2 + z^2 = 1\). We can represent this in two ways:

1. Cartesian Charts: Solving for \(z\) gives two functions \(z = \pm\sqrt{1 - x^2 - y^2}\). This requires two separate "patches" to cover the whole sphere. The bounds are \(-1\le x \le 1, -\sqrt{1-x^2}\le y \le \sqrt{1-x^2}\).

2. Spherical Coordinates: A more efficient single parametrization using angles \(\phi\) and \(\theta\):

  • \(x = \sin \phi \cos \theta\)
  • \(y = \sin \phi \sin \theta\)
  • \(z = \cos \phi\)

Where \(0 \le \phi \le \pi\) and \(0 \le \theta \le 2\pi\).

Example 3: Identifying a Surface

Identify the surface \(\vec{r}(u, v) = (u \cos v, u \sin v, u)\) for \(0 \le u \le 1\).

Solution:

We see that \(x = u \cos v\) and \(y = u \sin v\). Therefore, \(x^2 + y^2 = u^2(\cos^2 v + \sin^2 v) = u^2\).

Since \(z = u\), we substitute to find \(x^2 + y^2 = z^2\). This is the equation of a cone.

Example 4: Identifying a Surface (Complex Example)

Identify the surface \( \vec{r}(u, v) = (u \cos v, u \sin v, u^2 + v^2)\) for \(0 \le u, 0 \le v \le 2\pi\).

Solution:

From \(x = u \cos v\) and \(y = u \sin v\), we know \(x^2 + y^2 = u^2\).

Substitute into the \(z\) equation: \(z = u^2 + v^2 \implies z = x^2 + y^2 + v^2 \implies v^2 = z - x^2 - y^2\).

Also, \(\frac{y}{x} = \frac{u \sin v}{u \cos v} = \tan v\). Thus, \(v = \tan^{-1}(\frac{y}{x})\).

Combining these, the Cartesian relation is \( \tan(\sqrt{z - x^2 - y^2}) = \frac{y}{x}\).

Example 5: Parametrizing a Cylinder

Parametrize the surface \(x^2 + z^2 = 4\) where \(y \ge 0\).

Visual Description: A cylinder centered on the \(y\)-axis. The cross-section in the \(xz\)-plane is a circle with radius 2. The surface extends along the positive \(y\)-axis.

Solution:

Since the circle is in the \(xz\)-plane with radius 2, we use:

  • \(x = 2 \cos u\)
  • \(z = 2 \sin u\)
  • \(y = v\)

With domains \(0 \le u \le 2\pi\) and \(v \ge 0\).

Example 6: Parametrizing a Hyperboloid

Parametrize \(x^2 + y^2 - z^2 = 1\).

Solution:

Let \(x = u \cos v\) and \(y = u \sin v\). The equation becomes \(u^2 - z^2 = 1\).

Using the identity \(\sec^2 w - \tan^2 w = 1\), we can set \(u = \sec w\) and \(z = \tan w\). The final parametrization is:

\[\vec{r}(v, w) = (\sec w \cos v, \sec w \sin v, \tan w)\]
Example 7: Parametrizing a Plane

Parametrize the plane \(x + 2y + 3z = 6\).

Solution:

Solve for one variable, e.g., \(y = \frac{6 - x - 3z}{2}\).

Using \(x\) and \(z\) as parameters:

  • \(x = x\)
  • \(y = 3 - 0.5x - 1.5z\)
  • \(z = z\)

Tangent Planes to Parametrized Surfaces

Procedure for finding a Tangent Plane:

  1. Find partial derivative vectors \(\vec{r}_u = \frac{\partial \vec{r}}{\partial u}\) and \(\vec{r}_v = \frac{\partial \vec{r}}{\partial v}\). These are tangent to the surface.
  2. Calculate the normal vector using the cross product: \(\vec{n} = \vec{r}_u \times \vec{r}_v\).
  3. Use the point \(\vec{r}(u_0, v_0)\) and the normal vector \(\vec{n}\) to write the plane equation.
