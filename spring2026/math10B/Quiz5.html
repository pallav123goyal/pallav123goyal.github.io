Problem 1

Parametrize the line segment joining the point \( (1, 2, 3) \) to the point \( (3, -1, 3) \).

Solution:

To parametrize a line segment from a starting point \( P_0 \) to an ending point \( P_1 \), we use the vector-valued function \( \mathbf{r}(t) = \mathbf{r}_0 + t(\mathbf{r}_1 - \mathbf{r}_0) \) for the interval \( 0 \le t \le 1 \).

Step-by-Step Derivation:

  1. Assign the initial position vector: \( \mathbf{r}_0 = \langle 1, 2, 3 \rangle \).
  2. Assign the final position vector: \( \mathbf{r}_1 = \langle 3, -1, 3 \rangle \).
  3. Determine the direction vector \( \mathbf{v} = \mathbf{r}_1 - \mathbf{r}_0 \): \[ \mathbf{v} = \langle 3 - 1, -1 - 2, 3 - 3 \rangle = \langle 2, -3, 0 \rangle \]
  4. Formulate the parametric equations by combining the components: \[ x(t) = 1 + 2t \] \[ y(t) = 2 - 3t \] \[ z(t) = 3 \]

The final parametrization is \( \mathbf{r}(t) = \langle 1+2t, 2-3t, 3 \rangle \) for \( 0 \le t \le 1 \).

Problem 2

Set up an integral to evaluate the following line integral along the straight line path from \( (1, 2, 3) \) to \( (3, -1, 3) \):

\[ \int yz \, dx + x^2 \, dy + e^{xyz} \, dz \]

Solution:

Using the parametrization from Problem 1, we find the differentials with respect to \( t \):

  • \( dx = \frac{d}{dt}(1+2t) \, dt = 2 \, dt \)
  • \( dy = \frac{d}{dt}(2-3t) \, dt = -3 \, dt \)
  • \( dz = \frac{d}{dt}(3) \, dt = 0 \, dt \)

Substitute these expressions and the parametric forms of \( x, y, \) and \( z \) into the integral:

\[ \int_{0}^{1} \left( (2-3t)(3)(2) + (1+2t)^2(-3) + e^{(1+2t)(2-3t)(3)}(0) \right) dt \]

Setup Result:

\[ \int_{0}^{1} \left( 6(2-3t) - 3(1+2t)^2 \right) dt \]

Problem 3

Evaluate the integral that you set up in the previous problem.

Solution:

First, simplify the integrand by expanding the terms:

\[ 6(2-3t) - 3(1 + 4t + 4t^2) = 12 - 18t - 3 - 12t - 12t^2 \] \[ = -12t^2 - 30t + 9 \]

Integration Process:

Compute the definite integral from \( 0 \) to \( 1 \):

\[ \int_{0}^{1} (-12t^2 - 30t + 9) \, dt = \left[ -4t^3 - 15t^2 + 9t \right]_{0}^{1} \]

Applying the Fundamental Theorem of Calculus:

\[ (-4(1)^3 - 15(1)^2 + 9(1)) - (-4(0)^3 - 15(0)^2 + 9(0)) \] \[ = -4 - 15 + 9 = -10 \]

Final Answer: The value of the line integral is \( -10 \).
