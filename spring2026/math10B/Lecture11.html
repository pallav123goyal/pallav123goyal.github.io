Lecture 11: Line Integrals and Parametrization

1. Integrating Functions Over Curves

Graph Description: A Cartesian coordinate system showing a curve labeled \( f(x) \). The area between the curve and the x-axis, bounded by vertical lines at \( x = a \) and \( x = b \), is shaded with diagonal lines. An arrow points from the shaded region downwards, representing the area under the curve.

Recall that for a scalar function \( f(x) \), the area under the curve over an interval \( [a, b] \) is given by the standard definite integral:

\[ \text{Area} = \int_{a}^{b} f(x) \, dx \]

If the region of integration is not a simple interval \( [a, b] \), we use a path integral to find the area.

Definition: Path Integral

If the function is a scalar, the path integral along a curve \( c(t) \) is defined as:

\[ \int f(c(t)) \|c'(t)\| \, dt \]

Definition: Line Integral

If the function is vector-valued, we use a line integral. In general, to calculate the work done over a curve \( c(t) \), the line integral is defined as:

\[ \int f(c(t)) \cdot c'(t) \, dt \]

2. Examples of Line Integrals

Example 1: Computing a Line Integral in 3D Space

Compute the following integral along the curve \( c(t) = (1, t, e^t) \) for \( 0 \le t \le 1 \):

\[ \int \cos(z) \, dx + \int e^x \, dy + \int e^y \, dz \]

Solution:

This is the same as computing the line integral of the vector-valued function \( f(x,y,z) = (\cos(z), e^x, e^y) \) along the curve \( c(t) = (1, t, e^t) \).

First, we evaluate the function along the curve by substituting \( x=1 \), \( y=t \), and \( z=e^t \):

\[ f(c(t)) = (\cos(e^t), e^1, e^t) = (\cos(e^t), e, e^t) \]

Next, we compute the derivative of the curve \( c(t) \):

\[ c'(t) = (0, 1, e^t) \]

We then take the dot product of \( f(c(t)) \) and \( c'(t) \):

\[ f(c(t)) \cdot c'(t) = (\cos(e^t))(0) + (e)(1) + (e^t)(e^t) = e + e^{2t} \]

Now, we set up and evaluate the integral from \( t=0 \) to \( t=1 \):

\[ \int_{0}^{1} (e + e^{2t}) \, dt = \left[ et + \frac{e^{2t}}{2} \right]_{0}^{1} \] \[ = \left( e(1) + \frac{e^2}{2} \right) - \left( 0 + \frac{e^0}{2} \right) = e + \frac{e^2 - 1}{2} \]
Example 2: Integrating Over a Closed Curve

Graph Description: A Cartesian coordinate system showing a closed loop crossing the x and y axes. This represents an arbitrary closed path, such as the unit circle in the xy-plane.

Compute the integral of the function \( f(x,y) = y\hat{i} - x\hat{j} \) along the unit circle in the XY-plane.

Solution:

To proceed, we need to express our curve using a single variable. The equation for the unit circle is \( x^2 + y^2 = 1 \).

A standard parametrization for this curve is \( c(t) = (\cos(t), \sin(t)) \) for \( 0 \le t \le 2\pi \).

Evaluating the function and the derivative of the curve:

\[ f(c(t)) = \sin(t)\hat{i} - \cos(t)\hat{j} \] \[ c'(t) = -\sin(t)\hat{i} + \cos(t)\hat{j} \]

Taking the dot product gives:

\[ f(c(t)) \cdot c'(t) = (\sin(t))(-\sin(t)) + (-\cos(t))(\cos(t)) = -\sin^2(t) - \cos^2(t) = -1 \]

So, the line integral over the full circle is:

\[ \int_{0}^{2\pi} (-1) \, dt = -2\pi \]

What if we chose a different parametrization?

Suppose we parametrize the unit circle as \( s(t) = (\cos(2t), \sin(2t)) \) for \( 0 \le t \le \pi \).

\[ s'(t) = (-2\sin(2t), 2\cos(2t)) \] \[ f(s(t)) = \sin(2t)\hat{i} - \cos(2t)\hat{j} \] \[ f(s(t)) \cdot s'(t) = -2\sin^2(2t) - 2\cos^2(2t) = -2 \]

The integral evaluates to:

\[ \int_{0}^{\pi} (-2) \, dt = -2\pi \]

Conclusion: Any choice of parametrization is fine, as long as we walk the curve in the same direction (e.g., anti-clockwise) and cover the exact same path.

Example 3: Line Integral Along a Multi-Segment Path

Compute the integral \( \int z^2 \, dx + xy \, dz \) along the piecewise path connecting the points \( D(1,0,-1) \) to \( B(2,1,1) \) to \( C(1,1,2) \), and eventually back to the origin \( A(0,0,0) \).

Solution:

We will parametrize the segments of the shape separately. The vector field corresponding to the integral is \( f(x,y,z) = (z^2, 0, xy) \).

Step 1: Parametrize the line segment from D(1,0,-1) to B(2,1,1)

The direction vector from \( (1,0,-1) \) to \( (2,1,1) \) is:

\[ (2,1,1) - (1,0,-1) = \hat{i} + \hat{j} + 2\hat{k} = (1, 1, 2) \]

So, the equation of the line segment is \( c(t) = (1,0,-1) + t(1,1,2) = (1+t, t, -1+2t) \) with \( 0 \le t \le 1 \).

Plugging this into the function:

\[ f(c(t)) = ((-1+2t)^2, 0, t(1+t)) = (1-4t+4t^2, 0, t+t^2) \]

Taking the dot product with \( c'(t) = (1, 1, 2) \):

\[ f(c(t)) \cdot c'(t) = 1(1-4t+4t^2) + 0 + 2(t+t^2) = 1 - 2t + 6t^2 \]

Evaluating the integral for this segment:

\[ \int_{0}^{1} (1 - 2t + 6t^2) \, dt = \left[ t - t^2 + 2t^3 \right]_{0}^{1} = 1 - 1 + 2 = 2 \]
Step 2: Parametrize the line segment from B(2,1,1) to C(1,1,2)

The direction vector from \( (2,1,1) \) to \( (1,1,2) \) is:

\[ (1,1,2) - (2,1,1) = (-1, 0, 1) \]

The equation of the line segment is \( c(t) = (2,1,1) + t(-1, 0, 1) = (2-t, 1, 1+t) \) with \( 0 \le t \le 1 \).

Plugging this into the function:

\[ f(c(t)) = ((1+t)^2, 0, (2-t)(1)) = (1+2t+t^2, 0, 2-t) \]

Taking the dot product with \( c'(t) = (-1, 0, 1) \):

\[ f(c(t)) \cdot c'(t) = -1(1+2t+t^2) + 1(2-t) = -1 - 2t - t^2 + 2 - t = 1 - 3t - t^2 \]

Evaluating the integral for this segment:

\[ \int_{0}^{1} (1 - 3t - t^2) \, dt = \left[ t - \frac{3t^2}{2} - \frac{t^3}{3} \right]_{0}^{1} = 1 - \frac{3}{2} - \frac{1}{3} = -\frac{5}{6} \]
Step 3: Parametrize the line segment C from C(1,1,2) to A(0,0,0)

The direction vector from \( (1,1,2) \) to the origin \( (0,0,0) \) is:

\[ (0,0,0) - (1,1,2) = (-1, -1, -2) \]

The equation of the line segment is \( c(t) = (1,1,2) + t(-1, -1, -2) = (1-t, 1-t, 2-2t) \) with \( 0 \le t \le 1 \).

Plugging this into the function \( f(x,y,z) = (z^2, 0, xy) \):

\[ f(c(t)) = ((2-2t)^2, 0, (1-t)(1-t)) = (4 - 8t + 4t^2, 0, 1 - 2t + t^2) \]

Taking the dot product with \( c'(t) = (-1, -1, -2) \):

\[ f(c(t)) \cdot c'(t) = -1(4 - 8t + 4t^2) + 0 - 2(1 - 2t + t^2) \] \[ = -4 + 8t - 4t^2 - 2 + 4t - 2t^2 = -6 + 12t - 6t^2 \]

Evaluating the integral for this segment:

\[ \int_{0}^{1} (-6 + 12t - 6t^2) \, dt = \left[ -6t + 6t^2 - 2t^3 \right]_{0}^{1} = -6 + 6 - 2 = -2 \]
Step 4: Parametrize the line segment D from A(0,0,0) to D(1,0,-1)

The direction vector from \( (0,0,0) \) to \( (1,0,-1) \) is:

\[ (1,0,-1) - (0,0,0) = (1, 0, -1) \]

The equation of the line segment is \( c(t) = (0,0,0) + t(1, 0, -1) = (t, 0, -t) \) with \( 0 \le t \le 1 \).

Plugging this into the function:

\[ f(c(t)) = ((-t)^2, 0, t(0)) = (t^2, 0, 0) \]

Taking the dot product with \( c'(t) = (1, 0, -1) \):

\[ f(c(t)) \cdot c'(t) = 1(t^2) + 0(0) - 1(0) = t^2 \]

Evaluating the integral for this segment:

\[ \int_{0}^{1} t^2 \, dt = \left[ \frac{t^3}{3} \right]_{0}^{1} = \frac{1}{3} \]

Final Step: Combine all the paths

To find the overall line integral, we sum the integrals for all paths \( A, B, C, \text{and } D \)[cite: 98, 99]:

\[ \text{Total Integral} = \int_{D} + \int_{B} + \int_{C} + \int_{D} = 2 - \frac{5}{6} - 2 + \frac{1}{3} = -\frac{1}{2}. \]

3. The Fundamental Theorem of Line Integrals

Diagram Description: Two separate path lines, labeled \( c_1(t) \) and \( c_2(t) \). Both paths begin at a common starting point A and end at a common destination point B. This illustrates that for a conservative vector field, the path taken between two points does not change the value of the line integral.

We can compute \( \int \vec{f} \cdot d\vec{r} \) in general. However, for some special functions \( \vec{f} \), the line integrals along different paths between the same two points are equal.

Theorem: Fundamental Theorem of Line Integrals

Consider a curve \( c(t) \) where \( a \le t \le b \). Suppose the vector field \( \vec{f} \) is the gradient of a scalar potential function \( F \), such that \( \vec{f} = \nabla F \). Then:

\[ \int_{a}^{b} \vec{f} \cdot dc = F(c(b)) - F(c(a)) \]

Remark: Recall that for 1-variable functions, the Second Fundamental Theorem of Calculus establishes a similar relationship:

\[ \int_{a}^{b} f'(x) \, dx = f(b) - f(a) \]
