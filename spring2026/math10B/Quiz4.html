Problem 1

Consider the curve \(c(t) = (\sin(3t), \cos(3t), 4t)\) for \(t \in [0, \pi]\). Find the expression for the unit tangent vector to this curve.

Solution:

First, we find the velocity vector \(c'(t)\) by differentiating each component of the curve with respect to \(t\):

\[c'(t) = \left( \frac{d}{dt}\sin(3t), \frac{d}{dt}\cos(3t), \frac{d}{dt}4t \right) = (3\cos(3t), -3\sin(3t), 4)\]

Next, we calculate the magnitude of the velocity vector, which represents the speed along the curve:

\[\|c'(t)\| = \sqrt{(3\cos(3t))^2 + (-3\sin(3t))^2 + 4^2}\] \[\|c'(t)\| = \sqrt{9\cos^2(3t) + 9\sin^2(3t) + 16}\]

Using the trigonometric identity \(\cos^2(\theta) + \sin^2(\theta) = 1\), the expression simplifies to:

\[\|c'(t)\| = \sqrt{9(1) + 16} = \sqrt{25} = 5\]

The unit tangent vector \(\mathbf{T}(t)\) is obtained by dividing the velocity vector by its magnitude:

\[\mathbf{T}(t) = \frac{c'(t)}{\|c'(t)\|} = \left( \frac{3}{5}\cos(3t), -\frac{3}{5}\sin(3t), \frac{4}{5} \right)\]
Problem 2

Consider the function \(f(x,y,z) = xy + yz + zx\) and the curve \(c(t) = (2t, t, -2t)\) for \(0 \le t \le 2\).

(a) Path Integral Setup

Set up the path integral of the function \(f\) along the curve \(c\).

Solution:

To set up the path integral \(\int_c f \, ds\), we use the formula \(\int_a^b f(c(t)) \|c'(t)\| \, dt\).

First, we evaluate the function \(f\) along the path by substituting the components of \(c(t)\):

\[f(c(t)) = (2t)(t) + (t)(-2t) + (-2t)(2t) = 2t^2 - 2t^2 - 4t^2 = -4t^2\]

Then, we find the magnitude of the velocity vector \(c'(t) = (2, 1, -2)\):

\[\|c'(t)\| = \sqrt{2^2 + 1^2 + (-2)^2} = \sqrt{4 + 1 + 4} = \sqrt{9} = 3\]

Substituting these into the integral from \(t = 0\) to \(t = 2\):

\[\int_0^2 (-4t^2)(3) \, dt = \int_0^2 -12t^2 \, dt\]

(b) Integral Evaluation

Evaluate the integral found in part (a).

Solution:

We evaluate the definite integral using the power rule for integration:

\[\int_0^2 -12t^2 \, dt = \left[ -12 \cdot \frac{t^3}{3} \right]_0^2 = \left[ -4t^3 \right]_0^2\] \[= (-4 \cdot 2^3) - (-4 \cdot 0^3) = -32 - 0 = -32\]
