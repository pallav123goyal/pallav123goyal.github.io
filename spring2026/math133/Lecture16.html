Lecture 16 - Isometric transformations

Recall: Vector Representation and Length

A vector is an oriented line segment. Given a vector \(\vec{v}\) from the origin \((0,0)\) to \((x,y)\), the length of \(\vec{v}\) is defined by:

\[||\vec{v}|| = \sqrt{x^{2}+y^{2}}\]

Consider \(\vec{v}\) as the matrix:

\[\vec{v} = \begin{bmatrix} x \\ y \end{bmatrix}\]

Then, its transpose is \(\vec{v}^{T} = \begin{bmatrix} x & y \end{bmatrix}\). We can consider the product:

\[\vec{v}^{T}\vec{v} = \begin{bmatrix} x & y \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} x^{2}+y^{2} \end{bmatrix} = ||\vec{v}||^{2}\]

Hence, we have a handy matrix format for vector length:

\[||\vec{v}|| = \sqrt{\vec{v}^{T}\vec{v}}\]
Warning: The orders of multiplication matter. If we instead multiplied \(\vec{v}\vec{v}^{T}\), we would get a completely different size matrix: \[\vec{v}\vec{v}^{T} = \begin{bmatrix} x \\ y \end{bmatrix} \begin{bmatrix} x & y \end{bmatrix} = \begin{bmatrix} x^{2} & xy \\ xy & y^{2} \end{bmatrix} \neq \vec{v}^{T}\vec{v}\] This output is a \(2 \times 2\) matrix, not a \(1 \times 1\) single-element scalar value!

Linear and Affine Transformations

Definition: A function \(f: \mathbb{R}^{2} \rightarrow \mathbb{R}^{2}\) is called a linear transformation or a map if it can be written as: \[f(\vec{v}) = A\vec{v}\] where \(A\) is a fixed \(2 \times 2\) matrix.

If we write \(A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) and \(\vec{v} = \begin{pmatrix} x \\ y \end{pmatrix}\), then this mapping looks like:

\[f\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} ax+by \\ cx+dy \end{pmatrix}\]

Notice that each component of the output is just a linear combination of \(x\) and \(y\). Because of this setup, any true linear map must send the origin to the origin:

\[f\begin{pmatrix} 0 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}\]
Definition: A function \(f: \mathbb{R}^{2} \rightarrow \mathbb{R}^{2}\) is called an affine transformation if it looks like: \[f(\vec{v}) = A\vec{v} + \vec{w}\] where \(A\vec{v}\) is the linear part, and adding the vector \(\vec{w}\) gives a rigid translation shift.
Important: For this formula to work consistently, both the matrix \(A\) and the translation vector \(\vec{w}\) must be fixed constants that do not change based on what vector \(\vec{v}\) you plug into the function.

When is a Transformation an Isometry?

Definition: A mapping function \(f: \mathbb{R}^{2} \rightarrow \mathbb{R}^{2}\) is called an isometry if it preserves the distance between any two points. That means if you pick any points \(P\) and \(Q\), the distance between their transformed locations matches the initial distance exactly: \[|PQ| = |f(P)f(Q)|\]

Examples of isometries include standard reflections, rotations, and translations. On the other hand, rescaling/scaling actions by any factor \(\lambda \neq \pm 1\) do not keep lengths the same, so they are not isometries.

Since general affine transformations are made by doing a linear map and then adding a translation vector, and translations naturally preserve distances on their own, finding out if an affine map is an isometry boils down to looking at just its linear map part. So, let's look closely at the linear map format \(f(\vec{v}) = A\vec{v}\).

Lemma: A linear map \(f(\vec{v}) = A\vec{v}\) is an isometry if and only if it keeps the length of every single vector exactly the same. That is: \[|A\vec{v}|| = ||\vec{v}||\]
Proof:

Let's check this step-by-step from both sides:

Part 1: Assume \(f\) is an isometry. Suppose a vector \(\vec{v}\) starts at the origin \(O\) and goes out to a point \(P\).

If we apply our linear transformation, we get the new points:

\[f(O) = A\begin{bmatrix} 0 \\ 0 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}\] \[f(P) = A\vec{v}\]

Since \(f\) preserves distances, the original length of line segment \(OP\) must equal the final distance between the mapped points \(f(O)\) and \(f(P)\):

\[|OP| = |f(O)f(P)|\]

By our setup, the original distance \(|OP|\) is just the length of our vector, \(||\vec{v}||\). The new distance \(|f(O)f(P)|\) is the length of the transformed vector, \(||A\vec{v}||\). Putting those together proves the first part: \(||\vec{v}|| = ||A\vec{v}||\) works for every vector.

Visual Description of Vector Mapping: A diagram showing a vector arrow \(\vec{v}\) drawn from an origin point labeled \(O\) to a terminal point labeled \(P\). A separate point labeled \(Q\) is shown nearby in the coordinate space.

Part 2: Now let's assume that \(||A\vec{v}|| = ||\vec{v}||\) is true for all vectors. Let \(P\) and \(Q\) be any two random points in space.

Let \(\vec{v}\) be the vector that points from \(P\) directly to \(Q\). To find the distance between their new transformed positions, let's look at the vector connecting \(f(P)\) to \(f(Q)\):

\[\text{Vector from } f(P) \text{ to } f(Q) = f(Q) - f(P)\] \[= A\vec{Q} - A\vec{P} = A(\vec{Q} - \vec{P})\] \[= A\vec{v} = f(\vec{v})\]

The distance between the new points is just the length of this difference vector, which is \(||A\vec{v}||\). Because we assumed matrix multiplication doesn't change a vector's length, we know:

\[||A\vec{v}|| = ||\vec{v}||\]

Since the original vector length \(||\vec{v}||\) is exactly the starting line segment distance \(|PQ|\), we get \(|PQ| = |f(P)f(Q)|\). This proves that the map \(f\) is an isometry. \(\blacksquare\)

Orthogonal Matrices

To fully pinpoint isometries, we need to find all matrices \(A\) where \(||A\vec{v}|| = ||\vec{v}||\) works for every vector. Let's write things out with elements:

\[A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}, \quad \vec{v} = \begin{pmatrix} x \\ y \end{pmatrix}\]

The transformed vector is:

\[A\vec{v} = \begin{pmatrix} ax+by \\ cx+dy \end{pmatrix}\]

Using our scalar length formulas, this means:

\[||\vec{v}|| = \sqrt{x^{2}+y^{2}}\] \[||A\vec{v}|| = \sqrt{(ax+by)^{2} + (cx+dy)^{2}}\]

To keep lengths equal, we must satisfy:

\[\sqrt{x^{2}+y^{2}} = \sqrt{(ax+by)^{2} + (cx+dy)^{2}}\]

We can solve this by squaring both sides and grouping the \(x\) and \(y\) terms together. Or, we can use our slick matrix transpose tricks from earlier to simplify things:

\[||\vec{v}||^{2} = \vec{v}^{T}\vec{v}\] \[||A\vec{v}||^{2} = (A\vec{v})^{T}(A\vec{v}) = \vec{v}^{T}A^{T}A\vec{v}\]

Setting these two equal to each other gives:

\[\vec{v}^{T}\vec{v} = \vec{v}^{T}A^{T}A\vec{v}\]

We can insert a standard identity matrix \(I\) on the left to make the terms line up directly:

\[\vec{v}^{T}I\vec{v} = \vec{v}^{T}A^{T}A\vec{v}\]

Since this has to work out perfectly no matter what vector \(\vec{v}\) we pick, the inner matrix operators must match exactly. This gives us a key matrix requirement: \(A^{T}A = I\).

Definition: A real square matrix \(A\) is called orthogonal if its transpose multiplied by itself equals the identity matrix: \[A^{T}A = I\]
Theorem (Main Conclusion): An affine transformation \(f(\vec{v}) = A\vec{v} + \vec{w}\) is an isometry if and only if its structural transformation matrix \(A\) is an orthogonal matrix.

Examples and Properties

Example 1: Analyzing a Shearing Map

Let's look at a linear transformation given by the rule:

\[f\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x \\ x+y \end{pmatrix}\]

This is a horizontal shear map along the vertical y-axis direction. Is this transformation an isometry?

Step-by-Step Solution:

First, let's extract the system matrix \(A\) from our rule. Rewriting it as a matrix multiplication gives:

\[f\begin{pmatrix} x \\ y \end{pmatrix} = \begin{bmatrix} 1 & 0 \\ 1 & 1 \end{bmatrix} \begin{pmatrix} x \\ y \end{pmatrix} \implies A = \begin{bmatrix} 1 & 0 \\ 1 & 1 \end{bmatrix}\]

Next, find the transpose by flipping the rows and columns:

\[A^{T} = \begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix}\]

Now let's check if it's orthogonal by computing the product \(A^{T}A\):

\[A^{T}A = \begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} 1 & 0 \\ 1 & 1 \end{bmatrix} = \begin{bmatrix} (1\cdot1 + 1\cdot1) & (1\cdot0 + 1\cdot1) \\ (0\cdot1 + 1\cdot1) & (0\cdot0 + 1\cdot1) \end{bmatrix} = \begin{bmatrix} 2 & 1 \\ 1 & 1 \end{bmatrix}\]

Let's check this resulting matrix against the standard \(2 \times 2\) identity matrix:

\[\begin{bmatrix} 2 & 1 \\ 1 & 1 \end{bmatrix} \neq \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\]

Since \(A^{T}A \neq I\), the matrix is not orthogonal. Therefore, this shearing map is not an isometry.

What does an Orthogonal Matrix Mean Geometrically?

Let's check out what happens with the rows and columns of an orthogonal matrix. Take a general matrix:

\[A = \begin{bmatrix} a & b \\ c & d \end{bmatrix} \implies A^{T} = \begin{bmatrix} a & c \\ b & d \end{bmatrix}\]

Multiplying them together to set up our identity requirement gives:

\[A^{T}A = \begin{bmatrix} a & c \\ b & d \end{bmatrix} \begin{bmatrix} a & b \\ c & d \end{bmatrix} = \begin{bmatrix} a^{2}+c^{2} & ab+cd \\ ab+cd & b^{2}+d^{2} \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\]

Matching up the individual entries gives us three specific scalar equations:

  1. \(a^{2} + c^{2} = 1\)
  2. \(b^{2} + d^{2} = 1\)
  3. \(ab + cd = 0\)

If we view the columns of matrix \(A\) as two separate vectors, \(\vec{v}_{1} = \begin{bmatrix} a \\ c \end{bmatrix}\) and \(\vec{v}_{2} = \begin{bmatrix} b \\ d \end{bmatrix}\), these three equations tell us something neat via vector dot products:

\[\vec{v}_{1} \cdot \vec{v}_{1} = a^{2}+c^{2} = 1 \implies ||\vec{v}_{1}|| = 1\] \[\vec{v}_{2} \cdot \vec{v}_{2} = b^{2}+d^{2} = 1 \implies ||\vec{v}_{2}|| = 1\] \[\vec{v}_{1} \cdot \vec{v}_{2} = ab+cd = 0 \implies \vec{v}_{1} \perp \vec{v}_{2}\]
Corollary: The column vectors of any orthogonal matrix are always perpendicular to each other. On top of that, because each column vector has a unit length of exactly 1, they form an orthonormal basis for \(\mathbb{R}^{2}\).

Inverses of Orthogonal Matrices

Recall that the inverse of a square matrix \(A\) is another matrix written as \(A^{-1}\) that satisfies \(A^{-1}A = A A^{-1} = I\). If you think of \(A\) as a linear map action, then \(A^{-1}\) represents the exact undo/inverse action of that map.

For any regular \(2 \times 2\) matrix \(A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}\), the inverse is found using the formula:

\[A^{-1} = \frac{1}{ad-bc} \begin{bmatrix} d & -b \\ -c & a \end{bmatrix}\]

The bottom scaling factor \(ad-bc\) is called the determinant of \(A\), written as \(\det(A)\). This formula shows that finding a matrix inverse only makes sense when the determinant isn't zero! A matrix is invertible if and only if \(\det(A) \neq 0\).

Remark: Since an orthogonal matrix satisfies \(A^{T}A = I\), multiplying both sides by the inverse matrix \(A^{-1}\) gives a fantastic shortcut: \[A^{T} = A^{-1}\] This means that for any orthogonal linear transformation matrix, finding its inverse map is incredibly easy—it is completely identical to its transpose matrix!
