Lecture 14: Introduction to Vectors

One distinct downside of standard coordinate geometry is that algebraic computations can quickly become highly elaborate, tedious, and cumbersome. Vector geometry serves as a powerful solution to streamline calculations and elegantly represent transformations on plane figures.

Geometric Translations and Isometries

Consider a directed line segment \(OP\) in the Cartesian plane where the initial point is anchored at the origin \(O = (0,0)\) and the terminal point resides at \(P = (x,y)\). Suppose we define a rigid translation transformation \(f: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) by:

\[f(x,y) = (x+a, y+b)\]

Under this translation, the initial point \(O\) and the terminal point \(P\) are mapped onto their respective image points \(O'\) and \(P'\):

\[O' = f(0,0) = (a,b)\] \[P' = f(x,y) = (x+a, y+b)\]

Let us mathematically examine the structural properties preserved during this translation by verifying the geometric slope parameters of both paths:

\[\text{Slope of } OP = \frac{y - 0}{x - 0} = \frac{y}{x}\] \[\text{Slope of } O'P' = \frac{(y+b) - b}{(x+a) - a} = \frac{y}{x}\]

Because their slopes are mathematically equivalent, the lines containing segments \(OP\) and \(O'P'\) share the same angle of inclination, meaning they are strictly parallel (\(OP \parallel O'P'\)). Furthermore, since geometric translations are rigid distance-preserving mappings (isometries), the absolute metric lengths remain perfectly unchanged:

\[|OP| = |O'P'|\]
Example 1: Structural Proof of the Geometric Parallelogram

Show that the quadrilateral vertices \(OPP'O'\) constructed under a linear translation form a valid geometric parallelogram.

Diagram Description: A handwritten sketch depicting a classic parallelogram labeled counter-clockwise with vertices \(O\) at the bottom-left, \(P\) at the bottom-right, \(P'\) at the top-right, and \(O'\) at the top-left. A dashed diagonal transversal line is mapped from \(O\) to \(P'\). Matching single tick marks are placed on the horizontal opposite segments \(O'P'\) and \(OP\) to illustrate equivalence. Angle markers are sketched around the diagonal intersection points to visually reference alternate interior geometric angles.

Solution: To formally demonstrate that \(OPP'O'\) is a parallelogram, we need to show that both sets of opposite spatial line segments are parallel. We have already established that \(OP \parallel O'P'\). Now, we must prove that the remaining sides satisfy \(OO' \parallel PP'\).

Approach 1: Direct Coordinate Verification

We can analytically verify the statement by calculating the algebraic lines' gradients for segments \(OO'\) and \(PP'\):

\[\text{Slope of } OO' = \frac{b - 0}{a - 0} = \frac{b}{a}\] \[\text{Slope of } PP' = \frac{(y+b) - y}{(x+a) - x} = \frac{b}{a}\]

Since both lines yield an identical slope of \(\frac{b}{a}\), they must be strictly parallel (\(OO' \parallel PP'\)). Because both pairs of opposite edges are parallel, the shape constitutes a true parallelogram.

Approach 2: Coordinate-Free Euclidean Proof

Alternatively, we can show parallelism via synthetic Euclidean logic by evaluating triangles \(\Delta OPP'\) and \(\Delta P'O'O\) divided by the shared transversal diagonal path segment \(OP'\):

  1. We know from translation properties that line lengths match: \(|OP| = |O'P'|\).
  2. The internal transversal edge is shared identically by reflexive properties: \(|OP'| = |OP'|\).
  3. Since \(OP \parallel O'P'\), the alternate interior angles cut by the diagonal must match exactly: \(\angle POP' = \angle O'P'O\).

By applying the Side-Angle-Side (SAS) congruence criterion, we conclude that:

\[\Delta OPP' \cong \Delta P'O'O\]

Because corresponding parts of congruent triangles are identical (CPCTC), the matching remaining alternate interior angle dimensions must also be equal:

\[\angle OP'P = \angle P'OO'\]

Since these matching interior alternate angles are defined along the transversal line \(OP'\) separating segments \(OO'\) and \(PP'\), it follows from geometric law that \(OO' \parallel PP'\), completing our synthetic proof.

Foundational Concepts and Vector Rules

Definition: Equivalent Oriented Segments: Two oriented directed line segments \(\vec{PQ}\) and \(\vec{P'Q'}\) are defined to be formally equivalent if and only if they simultaneously fulfill all three of the following independent criteria:

  1. Length: They have the exact same geometric magnitude length as absolute segments (\(|PQ| = |P'Q'|\)).
  2. Slope: They have the identical coordinate line gradient, making them parallel (\(PQ \parallel P'Q'\)).
  3. Orientation: They point in the identical direction sense (they point toward the same terminal quadrant).

Important: Any two equivalent directed line segments specify the exact same vector. Hence, a vector is uniquely governed solely by its absolute length, line slope, and orientation direction. It operates independently of its precise initial spatial starting position or terminal ending point coordinates.

Definition: Vector Magnitude/Length: Given a general coordinate vector represented component-wise as \(\vec{v} = \langle v_1, v_2 \rangle\), its structural metric length is mathematically specified by the Pythagorean theorem:

\[|\vec{v}| = \sqrt{v_1^2 + v_2^2}\]

In standard coordinate physics and mathematics, it is regular convention to graph structural vectors with their initial tail pinned at the coordinate plane origin \((0,0)\) and their terminal arrowhead extending outward to the spatial coordinate position \((v_1, v_2)\).

Diagram Description: A Cartesian grid coordinate system displaying an arrowed vector line labeled \(\vec{v}\) starting precisely at origin \((0,0)\) and extending at an angle up and right, terminating directly at a marked dot point labeled with coordinates \((v_1, v_2)\).

Vector Arithmetic Operations

Unlike fixed static points in geometric space, vectors can be dynamically added and subtracted together! This unique property allows complex geometric motions to be evaluated via simple, structured algebraic rules.

Definition: Vector Addition (Parallelogram Law): Let two spatial vectors be defined in component format as \(\vec{v} = \langle a, b \rangle\) and \(\vec{w} = \langle c, d \rangle\). Geometrically, their resultant vector sum \(\vec{v} + \vec{w}\) is defined as the directed diagonal vector pointing across the unique parallelogram whose adjacent base edges are outlined by vectors \(\vec{v}\) and \(\vec{w}\).

Diagram Description: A Cartesian graph containing two primary vectors emerging from origin \(O\): a solid red vector \(\vec{v} = \langle a, b \rangle\) mapping along the bottom to point \(Q\), and a solid blue vector \(\vec{w} = \langle c, d \rangle\) mapping up and left toward point \(P\). Dashed red and blue lines are constructed from points \(P\) and \(Q\) respectively to meet at a terminal vertex \(R(x,y)\), outlining a balanced parallelogram. A long, bold black dashed line vector originating at \(O\) extends diagonally across the center to terminate directly at point \(R\), labeled as the resultant sum \(\vec{v} + \vec{w}\).

Let us analytically calculate the exact coordinates of the terminal vertex \(R(x,y)\) generated by the diagonal path sum \(\vec{OR} = \vec{v} + \vec{w}\). Based on the parallel properties of our parallelogram construct, we state the following slope equations:

  1. Since line segment \(PR \parallel OQ\), their geometric line slopes must be identical: \[\frac{y - d}{x - c} = \frac{b}{a} \implies a(y - d) = b(x - c) \implies bx - ay = bc - ad \quad \text{--- (Equation 1)}\]
  2. Since line segment \(QR \parallel OP\), their geometric line slopes must also be identical: \[\frac{y - b}{x - a} = \frac{d}{c} \implies c(y - b) = d(x - a) \implies dx - cy = ad - bc \quad \text{--- (Equation 2)}\]

Solving this system of simultaneous linear equations for the unknown coordinate variables \(x\) and \(y\) reveals:

\[x = a + c\] \[y = b + d\]

Thus, we can write vector addition algebraically via component-wise addition:

\[\vec{OR} = \vec{v} + \vec{w} = \langle a + c, b + d \rangle\]

This algebraic consistency allows us to represent the addition path interchangeably via head-to-tail placement compositions:

\[\vec{OR} = \vec{OQ} + \vec{QR} = \vec{OP} + \vec{PR}\]

Vector Interpretation of Mappings: Using this notation, an algebraic plane coordinate translation mapping \(f(x,y) = (x+a, y+b)\) can be interpreted as a simple vector sum. Let vector \(\vec{v} = \langle a, b \rangle\) represent the tracking shift rule, and let vector \(\vec{w} = \langle x, y \rangle\) serve as an arbitrary input vector. The operation becomes:

\[f(\vec{w}) = \vec{w} + \vec{v}\]

Historical Note: The term "Vector" comes literally from the Latin word meaning "carrier" or "one who conveys".

Vector Subtraction Geometric Rules

Let vectors be defined in standard component orientation position as \(\vec{v} = \vec{OQ} = \langle v_1, v_2 \rangle\) and \(\vec{w} = \vec{OP} = \langle w_1, w_2 \rangle\). Geometrically, subtracting vector \(\vec{w}\) from vector \(\vec{v}\) is achieved by adding the negative inverted vector (\(-\vec{w}\)) to \(\vec{v}\).

Diagram Description: A geometric vector construction showing vector \(\vec{w}\) pointing into the first quadrant toward point \(P\), and its exact inverse directional negation \(-\vec{w}\) stretching down into the third quadrant with equal length toward point \(P'\). Vector \(\vec{v}\) points to point \(Q\). The subtraction result \(\vec{v} - \vec{w}\) is drawn from the origin to a point \(R\), forming vector \(\vec{OR}\). A parallel validation line shows that \(\vec{OR}\) possesses the identical length, slope, and direction arrow as the direct displacement line segment drawn from point \(P\) to point \(Q\) (\(\vec{PQ}\)).

Algebraically, vector subtraction is executed by subtracting matching linear components:

\[\vec{v} - \vec{w} = \langle v_1 - w_1, v_2 - w_2 \rangle = \vec{OR}\]

Because the resulting origin-centered vector \(\vec{OR}\) shares perfect geometric length alignment, slope alignment, and direction sense with the directed line segment running directly from point \(P\) to point \(Q\) (\(|\vec{OR}| = |\vec{PQ}|\)), we can write vector subtraction directly as the directional displacement vector between the two points:

\[\vec{v} - \vec{w} = \vec{PQ}\]

Scalar Multiplication and Dilations

Let us choose coordinate points at the origin \(O = (0,0)\) and a generic location \(P = (x,y)\). If we construct a scaled point located at \(P' = (3x, 3y)\), it is mathematically incorrect to write this relationship as a direct multiplication of points (e.g., \(P' = 3P\) is undefined). However, utilizing precise vector notation, we can declare this scalar relationship as:

\[\vec{OP'} = 3\vec{OP}\]

We can verify the length of this scaled vector analytically using the magnitude formula:

\[|\vec{OP'}| = \sqrt{(3x - 0)^2 + (3y - 0)^2} = \sqrt{9x^2 + 9y^2} = 3\sqrt{x^2 + y^2} = 3|\vec{OP}|\]

Definition: Geometric Plane Dilation: A coordinate transformation function \(f: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) defined by mapping components to a scaling factor:

\[f(x,y)=(rx,rx)\]

for a choice of real number constant \(r \in \mathbb{R}\) is called a dilation. Using vector component notation, this operation is expressed directly via scalar vector multiplication:

\[f(\vec{v}) = r\vec{v}\]
Example 2: Isometry Conditions for Plane Dilations

Determine the exact real number values of the scalar parameter \(r\) for which a dilation transformation \(f(\vec{v}) = r\vec{v}\) forms a true rigid isometry.

Solution: For a plane transformation function to be classified as a valid distance-preserving isometry, it must maintain all absolute vector lengths unchanged, meaning \(|f(\vec{v})| = |\vec{v}|\) must hold true for all vectors.

Let us compute the absolute length of our dilated transformation vector:

\[|f(\vec{v})| = \sqrt{(rx)^2 + (ry)^2} = \sqrt{r^2(x^2 + y^2)} = |r|\sqrt{x^2 + y^2} = |r| \cdot |\vec{v}|\]

Setting this scaling magnitude equal to our original unscaled vector length requirement yields:

\[|r| \cdot |\vec{v}| = |\vec{v}| \implies |r| = 1 \implies r = \pm 1\]

Thus, a geometric dilation acts as a rigid, distance-preserving isometry if and only if \(r = 1\) (which represents the identity mapping) or \(r = -1\) (which represents a point reflection centered directly through the origin).
