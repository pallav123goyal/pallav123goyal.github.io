Lecture 15: Linear Algebra

Vector Geometry and Linear Combinations

Recall from the previous lecture that given vectors \(\vec{v}\) and \(\vec{w}\), we can perform fundamental operations such as vector addition (\(\vec{v} + \vec{w}\)) and scalar multiplication (\(c\vec{v}\), where \(c \in \mathbb{R}\)). These operations form the defining core rules of a vector space.

We observe an foundational one-to-one correspondence between the following sets:

  • Points in a plane \(S\)
  • Ordered pairs of real numbers \(\mathbb{R}^2\)
  • Vectors whose tail is situated at the origin

Definition 7: Given vectors \(\vec{v}\) and \(\vec{w}\), we define a linear combination as a vector of the form \[a\vec{v} + b\vec{w}\] where \(a, b \in \mathbb{R}\).

Suppose the scalar constants \(a\) and \(b\) are both positive values greater than \(1\). We can visualize this linear combination geometrically utilizing the parallelogram rule.

The vector \(\vec{v}\) points towards the lower-right of the quadrant, while \(\vec{w}\) points towards the upper-right. The diagonal vector stretching from the origin to the opposite corner of this parallelogram represents the resultant linear combination vector, labeled \(a\vec{v} + b\vec{w}\).

Linear Independence and Spanning Sets

Definition 8: Vectors \(\vec{v}\) and \(\vec{w}\) are linearly independent if they are not parallel. This is logically equivalent to stating that neither vector is a scalar multiple of the other.

Conversely, vectors that are parallel to one another are called linearly dependent.

Definition 9: Vectors \(\vec{v}\) and \(\vec{w}\) form a spanning set if every vector in \(\mathbb{R}^2\) can be written as a linear combination of these vectors.

Question: Spanning Property of Independent Vectors

Show that if \(\vec{v}\) and \(\vec{w}\) are linearly independent, then they span \(\mathbb{R}^2\).

Algebraic Solution:

Let \(\vec{v} = (v_1, v_2)\) and \(\vec{w} = (w_1, w_2)\). Since \(\vec{v}\) and \(\vec{w}\) are linearly independent, they are not parallel, which implies that they don't have the same slope. This is equivalent to saying that \(v_1w_2-v_2w_1\neq 0\).

Now consider an arbitrary target vector \(\vec{u} = (u_1, u_2) \in \mathbb{R}^2\). We seek scalars \(a, b \in \mathbb{R}\) satisfying the vector equation:

\[a\vec{v} + b\vec{w} = \vec{u}\]

Expressed in component matrix form, this yields the linear system:

\[av_1+bw_1=u_1\] \[av_2+bw_2=u_2.\]

We can solve these equations to get:

\[a=\frac{u_1w_2-u_2w_1}{v_1w_2-v_2w_1}, b=\frac{u_2v_1-u_1v_2}{v_1w_2-v_2w_1},\]

where we can be sure that the denominator is non-zero because of the linear independence conditions.

Geometric Solution:

Fix any vector \(\vec{u} \in \mathbb{R}^2\) with its tail anchored at the origin. Since \(\vec{v}\) and \(\vec{w}\) are not parallel, we can construct the following geometry:

Draw a line passing through the head of \(\vec{u}\) that runs parallel to vector \(\vec{v}\). This constructed line will intersect the line running through the origin in the direction of \(\vec{w}\) at a unique intersection point, which we label \(P\).

Because the segment \(\vec{OP}\) lies directly along the \(\vec{w}\)-line, it can be written as a scalar multiple: \(\vec{OP} = b\vec{w}\) for some scalar \(b \in \mathbb{R}\).

Next, consider the displacement vector \(\vec{u} - \vec{OP}\), which points from point \(P\) to the head of \(\vec{u}\). By our parallel line construction, this displacement is parallel to \(\vec{v}\), meaning \(\vec{u} - \vec{OP} = a\vec{v}\) for some scalar \(a \in \mathbb{R}\).

Rearranging this yields \(\vec{u} = a\vec{v} + b\vec{w}\). Therefore, every vector \(\vec{u} \in \mathbb{R}^2\) can be uniquely structured as a linear combination of \(\vec{v}\) and \(\vec{w}\), demonstrating that they span the space. \(\square\)

From the tip of \(\vec{u}\), a line is drawn parallel to vector \(\vec{v}\) until it intersects a line extending along vector \(\vec{w}\) at a point \(P\). The segment from the origin to \(P\) is marked as \(b\vec{w}\), and the segment from \(P\) to the tip of \(\vec{u}\) is marked as the parallel shift vector \(a\vec{v}\), visually demonstrating the vector addition \(\vec{u} = a\vec{v} + b\vec{w}\).

Linear Transformations

Definition 10: A linear transformation is a function \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) such that for any vector \(\vec{v} = \langle v_1, v_2 \rangle\), the components of the output vector \(T(\vec{v})\) are linear combinations of the input variables \(v_1\) and \(v_2\). Crucially, the constants forming these linear combinations are completely independent of \(\vec{v}\).

Question: Linearity Analysis

Determine whether the functions \(f(x, y) = (rx, ry)\), \(g(x, y) = (-x, y)\), and \(h(x, y) = (x + a, y + b)\) are linear transformations.

Solution:

Recall that a transformation \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) is strictly linear if and only if it preserves the zero vector and respects vector addition and scalar multiplication: \(T(\vec{0}) = \vec{0}\) and \(T(a\vec{u} + b\vec{v}) = aT(\vec{u}) + bT(\vec{v})\) for all vectors and scalars.

  • Analysis of \(f(x, y) = (rx, ry)\): This function represents scalar dilation by a factor of \(r\). It is a linear transformation. In standard matrix form, it is written as: \[f\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} r & 0 \\ 0 & r \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix}\]
  • Analysis of \(g(x, y) = (-x, y)\): This transformation represents a geometric reflection across the vertical y-axis. It is a linear transformation. In standard matrix form, it is written as: \[g\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} -1 & 0 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix}\]
  • Analysis of \(h(x, y) = (x + a, y + b)\): This function represents a vector translation. This is not a linear transformation since we can't express the output as a linear combination of the input with coefficients independent of the input.

Affine Transformations

Definition 11: An affine transformation is a function \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) of the mathematical form: \[T(\vec{x}) = A\vec{x} + \vec{b}\] where \(A\) is a constant \(2 \times 2\) matrix and \(\vec{b} \in \mathbb{R}^2\) is a constant displacement vector. Equivalently, an affine transformation can be characterized as a linear transformation followed immediately by a vector translation.

Matrix Representations

Every linear mapping \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) can be uniquely modeled via matrix multiplication using a standard \(2 \times 2\) matrix:

\[T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix}ax+by\\cx+dy\end{pmatrix}\]

for real constant coefficients \(a, b, c, d\).

Expanding the general matrix formulation for an affine mapping where matrix \(A\) and displacement vector \(\vec{b}\) are defined as:

\[A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}, \quad \vec{b} = \begin{pmatrix} p \\ q \end{pmatrix}\]

Applying this to a vector \(\vec{x} = \begin{pmatrix} x \\ y \end{pmatrix}\) yields the explicit algebraic coordinate form:

\[T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} + \begin{pmatrix} p \\ q \end{pmatrix} = \begin{pmatrix} ax + by + p \\ cx + dy + q \end{pmatrix}\]
Example 2.1: Rotation Matrices

Fact: Rotation matrices describe rigid rotations of the coordinate plane. In linear algebra, a counterclockwise rotation by an angle \(\theta\) centered about the origin is defined by the matrix:

\[A = \begin{pmatrix} \cos \theta & -\sin \theta \\ \sin \theta & \cos \theta \end{pmatrix}\]

If a point \(P = (x, y)\) is treated as a column vector, matrix multiplication provides the coordinates of the newly rotated point:

\[A \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x\cos \theta - y\sin \theta \\ x\sin \theta + y\cos \theta \end{pmatrix}\]

Geometrically, this matrix action uniformly spins every point in the plane about the origin by the specified angle \(\theta\). Because distances are preserved, a pure rotation matrix serves as an archetype of an isometry.

Definition: Given a standard matrix \(A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\), the scalar determinant is calculated using the formula:

\[\det(A) = ad - bc\]
The determinant has a few geometric interpretations. Firstly, it is equal to the signed area of the parallelogram that is determined by the vectors \(\langle a,b\rangle\) and \(\langle c,d\rangle\). Secondly, as a corollary of the previous fact, the determinant is zero exactly when these two vectors are linearly independent. Finally, the determinant being non-zero is equivalent to the associated linear transformation being invertible.
