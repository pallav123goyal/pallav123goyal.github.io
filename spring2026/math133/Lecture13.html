Lecture 13: Glide Reflections and Fixed Points

Review of Isometries

Recall that a map \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) is called an isometry if it preserves distances. Specifically, for any points \(P\) and \(Q\), the distance between them remains constant after the transformation:

\[|PQ| = |T(P)T(Q)|\]

Common examples of isometries include translations, reflections, and rotations.

Theorem: All isometries preserve angles. That is, for points \(P\), \(Q\), and \(R\), \(\angle PQR = \angle T(P)T(Q)T(R)\).

Proof: Let \(T\) be an isometry. Because \(T\) preserves distances, we have \(|PQ| = |T(P)T(Q)|\), \(|PR| = |T(P)T(R)|\), and \(|QR| = |T(Q)T(R)|\). By SSS (Side-Side-Side) congruence, \(\Delta PQR \cong \Delta T(P)T(Q)T(R)\). Consequently, the corresponding angles must be equal: \(\angle PQR = \angle T(P)T(Q)T(R)\).

Definition: Maps \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) that preserve angles are called conformal maps.

Glide Reflections

Definition: A map \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) is called a glide reflection if it is the result of a reflection followed by a translation in the direction of the line of reflection.

Note on Slope: Any translation can be viewed as \(f(x,y) = (x+a, y+b)\). We can think of this translation as having a "slope" of \(\frac{b}{a}\). If the slope of the line of reflection is equal to the slope of the translation (\(\frac{b}{a}\)), then the transformation is a glide reflection.

Example 1: Identifying a Glide Reflection

Consider the map \(f(x,y) = (x+3, -y)\). Is this a glide reflection?

Solution:

1. The map involves a reflection \((x,y) \mapsto (x, -y)\), which is a reflection about the x-axis. The slope of the x-axis is 0.

2. The map involves a translation \((x, -y) \mapsto (x+3, -y)\). Here, \(a=3\) and \(b=0\). The slope of this translation is \(\frac{0}{3} = 0\).

3. Since the slopes of the reflection line and the translation match, this is a glide reflection.

Example 2: A Non-Glide Reflection

Consider the map \(g(x,y) = (x, -y+3)\). Is this a glide reflection?

Solution:

1. The reflection is \((x,y) \mapsto (x, -y)\), about the x-axis (slope = 0).

2. The translation is \((x, -y) \mapsto (x, -y+3)\). Here, \(a=0\) and \(b=3\). The slope is undefined (\(\infty\)).

3. The slopes do not match; therefore, this is not a glide reflection.

Theorem: Glide reflections are isometries.

Proof: A glide reflection \(f\) is the composition of a reflection \(g\) and a translation \(h\) (\(f = h \circ g\)). For any points \(P, Q\):

\[|f(P)f(Q)| = |h(g(P))h(g(Q))| = |g(P)g(Q)| = |PQ|\]

The first equality holds because translations are isometries, and the second holds because reflections are isometries. Thus, the composition is an isometry.

Fixed Points

Definition: Given a map \(f: \mathbb{R}^2 \rightarrow \mathbb{R}^2\), a point \(P\) is called a fixed point if \(f(P) = P\).

Example 3: Finding Fixed Points

Find fixed points for the following maps:

  • a) Reflection: \(f(x,y) = (x, -y)\)
  • b) Translation: \(g(x,y) = (x+1, y-2)\)
  • c) Glide Reflection: \(h(x,y) = (x+3, -y)\)
  • d) Reflection about \(y=1\): \(i(x,y) = (x, 2-y)\)

Solutions:

a) Setting \((x, -y) = (x, y)\) gives \(x=x\) and \(-y=y \Rightarrow y=0\). Fixed points: all points on the x-axis \((x, 0)\).

b) Setting \((x+1, y-2) = (x, y)\) gives \(x+1=x\) (impossible). Result: No fixed points.

c) Setting \((x+3, -y) = (x, y)\) gives \(x+3=x\) (impossible). Result: No fixed points.

d) Setting \((x, 2-y) = (x, y)\) gives \(2-y=y \Rightarrow 2=2y \Rightarrow y=1\). Fixed points: all points on the line \(y=1\).

Visual Description: A diagram illustrates the reflection \(i(x,y) = (x, 2-y)\). It shows a horizontal dashed line at \(y=1\). A point \((x,y)\) above the line is a distance \(\alpha = y-1\) from the line. Its image \((x, y')\) is shown at an equal distance \(\beta = y-1\) below the line, resulting in \(y' = 1 - (y-1) = 2-y\).

Determining Isometry Type

Example 4: Identifying \(f \circ g\)

Consider \(f(x,y) = (y,x)\) and \(g(x,y) = (x, -y)\). Identify the composition \(f \circ g\).

Solution:

The composition is \(f(g(x,y)) = f(x, -y) = (-y, x)\).

To find the type of isometry, find the fixed points: \((-y, x) = (x, y) \Rightarrow -y=x\) and \(x=y\). This implies \(x=0, y=0\). The only fixed point is the origin \((0,0)\).

This suggests a rotation. Recall the rotation matrix for an angle \(\theta\):

\[h(x,y) = (x \cos\theta - y \sin\theta, x \sin\theta + y \cos\theta)\]

Equating this to \((-y, x)\):

  • \(\cos\theta = 0\)
  • \(\sin\theta = 1\)

This gives \(\theta = \pi/2\). Therefore, the composition is a rotation by 90 degrees anti-clockwise.

Example: Identifying the map \( f(x,y) = (-x, -y) \)

Step 1: Check if it is a translation.

A translation has the form \( (x+a, y+b) \). Here, the coefficients of \( x \) and \( y \) are \(-1\), not \(1\). Therefore, it is not a translation.

Step 2: Find the fixed points.

We solve for \( f(x,y) = (x,y) \):

\[ \begin{cases} -x = x \\ -y = y \end{cases} \]

This implies \( 2x = 0 \) and \( 2y = 0 \), so \( x=0 \) and \( y=0 \). The only fixed point is the origin \( (0,0) \).

Step 3: Conclusion from the flowchart.

Since there is exactly one fixed point, this isometry must be a rotation.

Step 4: Determine the angle of rotation.

Recall the general rotation formula for an angle \( \theta \): \( (x \cos\theta - y \sin\theta, x \sin\theta + y \cos\theta) \). Comparing this to our map \( (-x, -y) \):

  • \( \cos\theta = -1 \)
  • \( \sin\theta = 0 \)

This corresponds to \( \theta = \pi \) (or \( 180^\circ \)). Thus, the transformation is a rotation by 180 degrees about the origin.
