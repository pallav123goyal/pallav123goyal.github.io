Lecture 11: Movements in Coordinate Geometry

Translation

Definition: We say that a point \(p' = (x', y')\) is obtained from \(p = (x, y)\) by translation if there are some \(a, b \in \mathbb{R}\) such that:

\[x' = x + a\] \[y' = y + b\]

Definition: A function \(f: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) is called a translation if \(f(x, y) = (x+a, y+b)\) for some fixed \(a\) and \(b\).

Intuition: A translation moves a point \(a\) steps to the right and \(b\) steps upwards. This effectively increases the x-coordinate by \(a\) and the y-coordinate by \(b\).

Example 1: Translating Specific Points

Let the translation constants be \(a = 2\) and \(b = -1\). The translation function is defined as:

\[f(x, y) = (x + 2, y - 1)\]

Apply this function to the points \((0, 0)\), \((1, 0)\), and \((0, 1)\).

Solution:

  • \(f(0, 0) = (0 + 2, 0 - 1) = (2, -1)\)
  • \(f(1, 0) = (1 + 2, 0 - 1) = (3, -1)\)
  • \(f(0, 1) = (0 + 2, 1 - 1) = (2, 0)\)

Graph Description: The graph shows a set of points in the Cartesian plane. The original points—\((0,1)\) (green), \((0,0)\) (blue), and \((1,0)\) (red)—form a simple shape. After the translation \(f(x, y) = (x+2, y-1)\), these points shift right by 2 units and down by 1 unit to their new positions: \((2,0)\) (green), \((2,-1)\) (blue), and \((3,-1)\) (red).

Properties of Translations

Example 2: Preservation of Distance

Let \(f: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) be the translation \(f(x, y) = (x+2, y-1)\). Given two points \(P\) and \(Q\), is it true that the distance \(|PQ|\) is equal to the distance between their translated images \(|f(P)f(Q)|\)?

Solution:

Fix coordinates \(P = (p_1, p_2)\) and \(Q = (q_1, q_2)\).

The translated points are:

\[f(P) = (p_1 + 2, p_2 - 1)\] \[f(Q) = (q_1 + 2, q_2 - 1)\]

The distance between the translated points is:

\[|f(P)f(Q)| = \sqrt{((p_1 + 2) - (q_1 + 2))^2 + ((p_2 - 1) - (q_2 - 1))^2}\] \[= \sqrt{(p_1 - q_1)^2 + (p_2 - q_2)^2}\] \[= |PQ|\]

Thus, translations preserve the distance between points.

Example 3: Translation of a Straight Line

Suppose \(\ell\) is a straight line. Show that its image under translation \(f(\ell)\) is also a straight line.

Solution:

Consider a non-vertical line expressed as \(y = mx + c\). A point \(P\) on this line has the form \((x, mx + c)\).

Applying the translation \(f(P) = (x+2, mx+c-1)\), let the new coordinates be \((x', y')\):

\[x' = x + 2 \implies x = x' - 2\] \[y' = mx + c - 1\]

Substituting the expression for \(x\) into the equation for \(y'\):

\[y' = m(x' - 2) + c - 1\] \[y' = mx' - 2m + c - 1\]

Since this resulting equation is in the form \(y' = mx' + C\), it is the equation of a straight line. For vertical lines \(x = a\), the translated image is \(x = a + 2\), which is also a vertical straight line.

Example 4: Translation of a Circle

Let \(\mathcal{C}\) be a circle in the plane. Show that its image \(f(\mathcal{C})\) is also a circle.

Method 1: Algebraic Substitution

Let the circle be defined by \((x-h)^2 + (y-k)^2 = r^2\) with center \((h, k)\) and radius \(r\). Using the translation \(f(x, y) = (x+2, y-1)\), we set \(x' = x+2\) and \(y' = y-1\), so \(x = x'-2\) and \(y = y'+1\). Substituting these into the circle equation:

\[(x' - 2 - h)^2 + (y' + 1 - k)^2 = r^2\]

This is a circle with center \((h+2, k-1)\) and the same radius \(r\).

Method 2: Geometric Property

Suppose circle \(\mathcal{C}\) has center \(P\) and radius \(r\). If \(Q\) is any point on \(\mathcal{C}\), then \(|PQ| = r\). Since translations preserve distance, \(|f(P)f(Q)| = |PQ| = r\). This implies that \(f(Q)\) lies on a circle with center \(f(P)\) and radius \(r\).

Reflections

Definition: A function \(f: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) such that \(f(x, y) = (x, -y)\) is called a reflection about the x-axis.

Definition: Similarly, a function \(f: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) such that \(f(x, y) = (-x, y)\) is called a reflection about the y-axis.

Just like translations, reflections preserve distances, take lines to lines, and circles to circles. These facts are proved in the same way as they were for translations.

Example 5: Minimizing Distance to a Line

Given points \(P = (2, 4)\) and \(Q = (5, 7)\), find a point \(R\) on the x-axis such that the sum of distances \(|PR| + |RQ|\) is minimized.

Solution:

Let \(R = (x, 0)\). We want to minimize \(f(x) = \sqrt{(x-2)^2 + 4^2} + \sqrt{(x-5)^2 + 7^2}\).

Geometrical Approach: Reflect point \(P\) across the x-axis to get \(P' = (2, -4)\). Because \(|PR| = |P'R|\), minimizing \(|PR| + |RQ|\) is identical to minimizing \(|P'R| + |RQ|\).

This sum is minimized when \(P'\), \(R\), and \(Q\) are collinear. The line connecting \(P'(2, -4)\) and \(Q(5, 7)\) has the equation:

\[\frac{y - (-4)}{x - 2} = \frac{7 - (-4)}{5 - 2} = \frac{11}{3}\] \[y + 4 = \frac{11}{3}(x - 2)\]

Setting \(y = 0\) to find the intersection with the x-axis:

\[4 = \frac{11}{3}(x - 2) \implies 12 = 11x - 22 \implies 11x = 34 \implies x = \frac{34}{11}\]

The optimal point is \(R = (\frac{34}{11}, 0)\).
